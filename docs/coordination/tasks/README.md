# Folio Coordination Task Files

GPT0 publishes one Markdown task file per specialist assignment in this folder.

## File naming

FOLIO-YYYYMMDD-AREA-NNN.md

## Rules

- A task file is authoritative only when linked from docs/coordination/TASK_BOARD.md.
- READY means the specialist may start after receiving the short MULAI trigger from the CEO.
- DRAFT and WAITING tasks must not be started.
- Each task has exactly one assigned GPT role and one exact base SHA.
- GPT0 owns task files and the Task Board. Specialists read task files but do not edit them.
- Detailed specialist results belong in the assigned GitHub PR/Issue. GPT0 consolidates the verified result into AGENT_REPORTS.md.
- Do not put credentials, tokens, personal data, or secrets in task files.
