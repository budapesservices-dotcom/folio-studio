# Folio Vision

**Document ID:** FOLIO-PRODUCT-002  
**Status:** Agreed product direction  
**Product:** Folio

## Vision statement

**A creative, visual-first full-stack development studio where people can turn ambitious digital ideas into real products, regardless of the limitations of their tools, while designers and developers remain free to work in the way that suits them best.**

## The future Folio is working toward

Folio aims to become a unified creative development environment: a place where visual design, structure, behavior, source code, backend integration, runtime, and collaboration are connected through one coherent project.

Its experience should combine the immediacy and visual organization of a creative workstation with the depth and freedom of a professional development environment. The ambition is often described as **FL Studio for Web Development**: a strong creative-workspace metaphor, not a requirement to copy another application's interface or behavior.

In that future:

1. **Visual and code workflows coexist.** A designer can build visually, while a developer can inspect and refine the actual implementation.
2. **The project remains unified.** Specialized workspaces operate on shared project truth rather than maintaining disconnected copies.
3. **The environment is extensible.** New engines, tools, applications, and workflows can be added without repeatedly dismantling the foundation.
4. **Projects remain portable.** The native .flop project format carries the project and its supported relationships through explicit versioning and migration.
5. **AI can work with the real project context.** AI assistance should understand project structure and authorized operations, not merely produce detached snippets.
6. **Performance is a product value.** Efficient foundations and progressive workflows should help people create more with limited resources.

## What success should feel like

- A visual creator can express an idea without first having to translate every thought into code.
- A developer never has to surrender meaningful control merely to use the visual environment.
- Moving between workspaces does not feel like moving between unrelated products.
- The project can grow from a small idea into a complex application without losing structural integrity.
- The workspace feels like a creative instrument, while the underlying system behaves like dependable engineering software.

## Scope and honesty

This vision describes a long-term destination, not a claim about current functionality. Each capability must be classified in the architecture and roadmap as agreed, proposed, open, implemented, or verified. A feature is not complete because it appears in this document.
